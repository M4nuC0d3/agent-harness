# PR 1 — Runtime Foundation

## Ziel

Der bestehende instruction-first Harness bekommt eine kleine, optionale Runtime-Schicht.

Dieser PR führt vier Bausteine ein:

* strukturierte, versionierte Execution Events
* persistente Run-/Harness-State-Information
* eine deterministische Context-Policy
* ein maschinenlesbares Verification-/Eval-Modell

`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, bestehende Skills und bestehende Agent-Rollen bleiben unverändert.

## Anwendung

```bash
git apply 0001-runtime-foundation.patch
```

Danach:

```bash
python3 -m unittest discover -s harness/tests -v
python3 -m harness.runtime --show-config
```

Die Runtime ist in diesem PR noch **nicht automatisch in den Agent Loop eingehängt**. Das ist absichtlich so: PR 1 etabliert zunächst das Datenmodell und die deterministischen Bausteine, ohne das bestehende Verhalten zu verändern.

+"""Structured append-only execution events.
+
+Events are deliberately small and JSON serialisable. Payloads may contain
+provider-specific data, but the runtime only depends on the common envelope.
+"""
+
+from __future__ import annotations
+
+import json
+import uuid
+from dataclasses import asdict, dataclass, field
+from datetime import datetime, timezone
+from pathlib import Path
+from typing import Any
+
+
+def utc_now() -> str:
+    return datetime.now(timezone.utc).isoformat(timespec="seconds")
+
+
+@dataclass(frozen=True)
+class HarnessEvent:
+    """One immutable event in an agent run."""
+
+    type: str
+    run_id: str
+    harness_version: str
+    event_id: str = field(default_factory=lambda: str(uuid.uuid4()))
+    timestamp: str = field(default_factory=utc_now)
+    agent: str = "main"
+    tool: str | None = None
+    payload: dict[str, Any] = field(default_factory=dict)
+
+    def to_dict(self) -> dict[str, Any]:
+        return asdict(self)
+
+    def to_json(self) -> str:
+        return json.dumps(
+            self.to_dict(),
+            ensure_ascii=False,
+            sort_keys=True,
+        )
+
+
+class EventLog:
+    """Append-only JSONL event store.
+
+    The implementation is intentionally boring: one JSON object per line.
+    This makes the trace usable with jq, Python, grep and future storage
+    adapters without introducing a database dependency.
+    """
+
+    def __init__(self, path: str | Path):
+        self.path = Path(path)
+
+    def append(self, event: HarnessEvent) -> None:
+        self.path.parent.mkdir(parents=True, exist_ok=True)
+        with self.path.open("a", encoding="utf-8") as handle:
+            handle.write(event.to_json())
+            handle.write("\n")
+
+    def read(self) -> list[HarnessEvent]:
+        if not self.path.exists():
+            return []
+
+        events: list[HarnessEvent] = []
+        with self.path.open("r", encoding="utf-8") as handle:
+            for line in handle:
+                if not line.strip():
+                    continue
+                events.append(HarnessEvent(**json.loads(line)))
+        return events
+
+    def count(self, event_type: str | None = None) -> int:
+        if event_type is None:
+            return len(self.read())
+        return sum(event.type == event_type for event in self.read())
+

+"""Minimal YAML manifest loader.
+
+The harness intentionally has no PyYAML dependency. The manifest format used
+by this first PR is a restricted YAML subset: mappings, scalar values and
+lists. Unsupported YAML constructs fail loudly.
+"""
+
+from __future__ import annotations
+
+import re
+from dataclasses import dataclass
+from pathlib import Path
+from typing import Any
+
+
+DEFAULT_MANIFEST = {
+    "version": 1,
+    "runtime": {
+        "max_iterations": 30,
+        "max_tool_calls": 150,
+        "max_retries_per_subtask": 2,
+    },
+    "context": {
+        "max_items": 24,
+        "recent_events": 12,
+        "include_task": True,
+        "include_progress": True,
+        "include_memory": False,
+    },
+    "verification": {
+        "required": ["tests", "build"],
+        "fail_closed": True,
+    },
+    "recovery": {
+        "repeated_failure_threshold": 2,
+        "context_reset_after": 2,
+        "escalate_after": 3,
+    },
+    "optimizer": {
+        "enabled": False,
+        "require_regression_eval": True,
+        "require_human_approval": True,
+    },
+}
+
+
+def _scalar(value: str) -> Any:
+    value = value.strip()
+    if not value:
+        return {}
+    if value in {"true", "True"}:
+        return True
+    if value in {"false", "False"}:
+        return False
+    if value in {"null", "None"}:
+        return None
+    if re.fullmatch(r"-?\d+", value):
+        return int(value)
+    if re.fullmatch(r"-?\d+\.\d+", value):
+        return float(value)
+    if (
+        len(value) >= 2
+        and value[0] == value[-1]
+        and value[0] in {"'", '"'}
+    ):
+        return value[1:-1]
+    if value.startswith("[") and value.endswith("]"):
+        body = value[1:-1].strip()
+        if not body:
+            return []
+        return [_scalar(item) for item in body.split(",")]
+    return value
+
+
+def _load_restricted_yaml(path: Path) -> dict[str, Any]:
+    """Parse the small YAML subset used by the harness manifest."""
+    root: dict[str, Any] = {}
+    stack: list[tuple[int, dict[str, Any]]] = [(-1, root)]
+
+    for number, raw in enumerate(path.read_text(encoding="utf-8").splitlines(), 1):
+        if not raw.strip() or raw.lstrip().startswith("#"):
+            continue
+
+        indent = len(raw) - len(raw.lstrip(" "))
+        text = raw.strip()
+
+        if text.startswith("- "):
+            raise ValueError(
+                f"{path}:{number}: block lists are not supported; "
+                "use inline lists"
+            )
+
+        if ":" not in text:
+            raise ValueError(f"{path}:{number}: expected key: value")
+
+        key, value = text.split(":", 1)
+        key = key.strip()
+        value = value.strip()
+
+        while stack[-1][0] >= indent:
+            stack.pop()
+
+        parent = stack[-1][1]
+        if value:
+            parent[key] = _scalar(value)
+        else:
+            child: dict[str, Any] = {}
+            parent[key] = child
+            stack.append((indent, child))
+
+    return root
+
+
+@dataclass(frozen=True)
+class HarnessManifest:
+    """Loaded and validated harness configuration."""
+
+    data: dict[str, Any]
+
+    @classmethod
+    def load(cls, path: str | Path = ".harness/manifest.yaml") -> "HarnessManifest":
+        path = Path(path)
+        if not path.exists():
+            return cls(dict(DEFAULT_MANIFEST))
+
+        data = _load_restricted_yaml(path)
+        if data.get("version") != 1:
+            raise ValueError("unsupported harness manifest version")
+
+        return cls(data)
+
+    @property
+    def version(self) -> int:
+        return int(self.data["version"])
+
+    def section(self, name: str) -> dict[str, Any]:
+        value = self.data.get(name, {})
+        if not isinstance(value, dict):
+            raise ValueError(f"manifest section {name!r} must be a mapping")
+        return value
+

+        path.parent.mkdir(parents=True, exist_ok=True)
+        temporary = path.with_suffix(path.suffix + ".tmp")

+            encoding="utf-8",
+        )
+        temporary.replace(path)
+

+        path = Path(path)
+        return cls(**json.loads(path.read_text(encoding="utf-8")))

+"""Deterministic context selection.
+
+This is deliberately not an LLM summariser. It selects already-known facts
+according to policy. A future PR can add model-assisted compaction without
+changing the public interface.
+"""
+
+from __future__ import annotations
+
+from dataclasses import dataclass
+from typing import Iterable
+
+
+@dataclass(frozen=True)
+class ContextPolicy:
+    max_items: int = 24
+    recent_events: int = 12
+    include_task: bool = True
+    include_progress: bool = True
+    include_memory: bool = False
+
+
+@dataclass(frozen=True)
+class ContextItem:
+    kind: str
+    content: str
+    priority: int = 0
+
+
+class ContextManager:
+    """Build a bounded context from explicit inputs."""
+
+    def __init__(self, policy: ContextPolicy | None = None):
+        self.policy = policy or ContextPolicy()
+
+    def build(
+        self,
+        *,
+        task: str | None = None,
+        progress: str | None = None,
+        events: Iterable[ContextItem] = (),
+        memory: Iterable[ContextItem] = (),
+    ) -> list[ContextItem]:
+        selected: list[ContextItem] = []
+
+        if self.policy.include_task and task:
+            selected.append(ContextItem("task", task, priority=100))
+
+        if self.policy.include_progress and progress:
+            selected.append(ContextItem("progress", progress, priority=90))
+
+        event_items = list(events)
+        if self.policy.recent_events:
+            event_items = event_items[-self.policy.recent_events :]
+        selected.extend(event_items)
+
+        if self.policy.include_memory:
+            selected.extend(memory)
+
+        # Stable ordering: priority first, original order for equal priority.
+        selected = sorted(
+            enumerate(selected),
+            key=lambda pair: (-pair[1].priority, pair[0]),
+        )
+
+        return [item for _, item in selected[: self.policy.max_items]]
+

+"""Machine-readable verification results.
+
+The verifier is intentionally independent from any model. Commands are not
+executed by this module yet; this PR defines the contract that existing
+project-specific evaluators can emit.
+"""
+
+from __future__ import annotations
+
+from dataclasses import dataclass, field
+from enum import Enum
+from typing import Any
+
+
+class VerificationStatus(str, Enum):
+    PASS = "PASS"
+    FAIL = "FAIL"
+    BLOCKED = "BLOCKED"
+
+
+@dataclass(frozen=True)
+class VerificationCheck:
+    name: str
+    status: VerificationStatus
+    evidence: str = ""
+    findings: tuple[str, ...] = ()
+    command: str | None = None
+
+    def to_dict(self) -> dict[str, Any]:
+        return {
+            "name": self.name,
+            "status": self.status.value,
+            "evidence": self.evidence,
+            "findings": list(self.findings),
+            "command": self.command,
+        }
+
+
+@dataclass(frozen=True)
+class VerificationResult:
+    status: VerificationStatus
+    checks: tuple[VerificationCheck, ...] = ()
+    score: float = 0.0
+    summary: str = ""
+    blocking: bool = True
+
+    @classmethod
+    def from_checks(
+        cls,
+        checks: list[VerificationCheck],
+        *,
+        summary: str = "",
+    ) -> "VerificationResult":
+        if any(check.status == VerificationStatus.BLOCKED for check in checks):
+            status = VerificationStatus.BLOCKED
+        elif any(check.status == VerificationStatus.FAIL for check in checks):
+            status = VerificationStatus.FAIL
+        else:
+            status = VerificationStatus.PASS
+
+        passed = sum(
+            check.status == VerificationStatus.PASS for check in checks
+        )
+        score = passed / len(checks) if checks else 0.0
+
+        return cls(
+            status=status,
+            checks=tuple(checks),
+            score=score,
+            summary=summary,
+            blocking=status != VerificationStatus.PASS,
+        )
+
+    def to_dict(self) -> dict[str, Any]:
+        return {
+            "status": self.status.value,
+            "score": self.score,
+            "summary": self.summary,
+            "blocking": self.blocking,
+            "checks": [check.to_dict() for check in self.checks],
+        }
+
+    def is_accepted(self) -> bool:
+        """Only a complete PASS can be accepted."""
+        return self.status == VerificationStatus.PASS and not self.blocking
+

## Warum ich Schritt 1–4 genau so schneiden würde

### 1. Trace

Die bestehende `trace.py` schreibt bereits `.agent/trace.jsonl`, aber bisher nur einen kleinen Audit-Datensatz mit `ts`, `session`, `agent`, `tool` und `summary`.

Der Patch **behält diese Felder absichtlich** und ergänzt:

```text
event_id
event_type
run_id
harness_version
payload
```

Damit brechen bestehende `jq`-Auswertungen nicht.

Außerdem speichert `payload` zunächst **keine Tool-Argumente oder Tool-Ausgaben**, sondern nur deren Keys. Das ist bewusst datensparsamer und verhindert, dass wir mit dem neuen Trace versehentlich Secrets oder riesige Tool-Outputs persistieren.

---

### 2. Versionierung

Das ist für den späteren Self-Improvement-Loop entscheidend.

Ein Trace sagt künftig nicht nur:

```text
tool_call
```

sondern:

```text
run = abc
harness = 0.2.0
```

Damit können wir später sauber auswerten:

```text
Harness 0.2.0
→ 82 % success

Harness 0.2.1
→ 86 % success
```

und irgendwann:

```text
proposal #17
→ changed context policy
→ +4.1 % success
→ -7 % token usage
```

---

### 3. Context Manager

Hier würde ich **noch ausdrücklich keine LLM-basierte Zusammenfassung** einbauen.

Der erste Schritt ist deterministisch:

```text
Task
 ↓
Progress
 ↓
recent events
 ↓
optional memory
 ↓
bounded context
```

Damit haben wir später eine saubere Schnittstelle für:

```text
ContextManager
    ↓
ContextCompactor
    ↓
Model
```

ohne jetzt schon einen zweiten Agenten einzubauen, der „den Kontext zusammenfasst“.

Das ist wichtig, weil wir sonst gleich zwei ungetestete intelligente Komponenten einführen.

---

### 4. Verification

Das bestehende Repo hat bereits einen sehr guten Grundsatz: Der Evaluator muss jedes Ergebnis gaten; die Golden Tasks testen explizit, dass ein FAIL nicht akzeptiert wird.

Der Patch macht daraus einen **maschinenlesbaren Vertrag**:

```text
PASS
  ↓
accepted

FAIL
  ↓
blocked
  ↓
revision

BLOCKED
  ↓
blocked
  ↓
human/environment
```

Besonders wichtig ist:

```python
result.is_accepted()
```

und nicht:

```python
if score > 0.5:
    accept()
```

Ein einziger fehlgeschlagener **required check** darf nicht durch andere grüne Checks „weg-gemittelt“ werden. Das entspricht auch dem bestehenden Golden-Task-Prinzip, dass ein FAIL des Evaluators Acceptance blockiert.

---

## Eine Sache würde ich vor dem tatsächlichen Merge noch ändern

Im Patch ist der Manifest-Loader absichtlich klein gehalten. **Ich würde in einem echten PR wahrscheinlich doch TOML statt YAML für `.harness/manifest` nehmen**, weil Python dafür seit langem `tomllib` in der Standardbibliothek hat.

Dann wäre:

```text
.harness/manifest.toml
```

statt:

```text
.harness/manifest.yaml
```

technisch sauberer und wir könnten den kompletten selbstgebauten YAML-Parser entfernen.

Für ein echtes Repo würde ich daher sogar diese Variante bevorzugen:

```toml
version = 1

[runtime]
max_iterations = 30
max_tool_calls = 150
max_retries_per_subtask = 2

[context]
max_items = 24
recent_events = 12
include_task = true
include_progress = true
include_memory = false
```

**Das würde ich vor dem Commit nehmen.**

Der Grund ist auch konzeptionell passend: `AGENTS.md` bleibt Markdown, weil es eine **Agent-facing Instruction API** ist; Runtime-Konfiguration ist maschinenorientiert und sollte daher ein maschinenfreundliches Format haben.
